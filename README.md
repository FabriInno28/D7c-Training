# 10 Minuten on Top

Auslieferbare erste Trainingseinheit für Fussballerinnen und Fussballer von 10 bis 12 Jahren.

## Aktueller Umfang

Die Trainingswelt ist der Einstieg. Aktiv ist Station 6 «Stark wie ein Fels».

Die Einheit umfasst:

1. Tiefe Hocke
2. Seitenstütze
3. Beckenlift
4. Superman
5. Ruhiger Abschluss
